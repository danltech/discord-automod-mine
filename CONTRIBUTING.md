# 🤝 Contribution Guidelines

Wir freuen uns über jeden Beitrag, sei es die Verbesserung unserer Wortlisten, das Melden von Bugs oder die vorgeschlagene Code-Optimierung.

## ✅ Wie man beiträgt

1.  **Forken:** Erstellen Sie einen Fork dieses Repositorys.
2.  **Branch erstellen:** Erstellen Sie einen neuen Branch für Ihre Änderungen (`git checkout -b feature/mein-beitrag`).
3.  **Änderungen vornehmen:** Führen Sie Ihre Verbesserungen durch (z.B. Hinzufügen von Wörtern zu den Textdateien, Bugfixes im Code).
4.  **Commiten und Pushen:** Commiten Sie Ihre Änderungen und pushen Sie sie in Ihren Fork (`git commit -m 'Feat: Neues Wort hinzugefügt'`).
5.  **Pull Request (PR):** Erstellen Sie einen Pull Request zu unserem Haupt-Repository.

## 📝 Spezifische Hinweise für die Wortlisten

Wenn Sie neue Wörter vorschlagen, geben Sie bitte an:
1.  Das **Wort/Muster**.
2.  Die **Kategorie** (`low`, `medium`, `high`, `critical`), zu der es gehört.
3.  Eine kurze **Begründung**, warum dieses Wort in dieser Kategorie eingeordnet wird (z.B. "Ist eine subtile, aber beleidigende Bezeichnung für einen Spieler").

## 🐛 Bug Reports

Wenn Sie einen Fehler finden, beschreiben Sie bitte:
*   Die Schritte, um den Fehler zu reproduzieren.
*   Die erwartete Ausgabe vs. die tatsächliche Ausgabe.
*   Welche Version des Bots/der Wordlist Sie verwenden.

Vielen Dank für Ihren Beitrag!
